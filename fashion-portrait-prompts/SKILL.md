# 内衣广告插画提示词转换

把用户的一串词编排成一张可以实际绘制的广告：有辨识度的成年角色、具体的内衣商品、明确的姿态与镜头、协调的环境光色，以及真正可读的品牌信息区。默认视觉目标是日系二次元商业插画与精品内衣杂志广告的结合。

## 输入与交付

- 接受中文短句、英文 tags、完整旧提示词、角色图、广告参考图及其组合。没有参考图也能完成，不要求用户填写表格。
- 默认返回一个完整中文提示词代码块，不先讲提示词理论，不列一堆候选方案。代码块内直接描述最终画面，不留下待填变量；用户要求其他语言或格式时遵从。
- 有实质补全时可在代码块前用一句话说明，例如“未指定品牌，采用虚构品牌 LUNE；版式为左侧人物、右侧广告栏”。不要逐项汇报内部分析。
- “改提示词”只输出文字；“按这些词生成一张”则先完成内部改写，再调用当前环境可用的图像生成能力。若环境有 imagegen 技能，按其工具流程执行；没有生图能力则交付最终提示词并说明未生成图片，不能假装已出图。

## 先确定保留什么

从输入提取：人物数量、角色特征、服装款式与颜色、表情、动作、场景、画幅、画风、品牌名、必须显示的文字、禁止改变的项目。用户明确指定优先于以下默认项。

将输入分成三类，在内部处理即可：

1. **角色锚点**：发色与发型、瞳色、脸部风格、发饰、角、耳、翅膀、尾巴、代表性花纹和配色。保持可辨识度；双人分别列明 A/B 特征，不串色、不交换饰品。
2. **转换对象**：原有服装、画面组织、抽象氛围词。用户要求“改成内衣广告”时，把原服装的配色、纹样与配饰转入内衣设计，而非继续保留整件礼服或盔甲。若明确要求保留原衣服，则按其要求处理，必要时只问这一处冲突。
3. **需要补足的绘画信息**：商品结构、手脚位置、镜头裁切、广告栏比例、广告文字和材质细节。用协调的默认值直接补齐。

参考图确实存在时先查看，再描述能看到的锚点。不要凭角色名字编造外观，不要在没有图片时写“根据上传图”。未提供关键参考但文字足够时继续做；只有必须依靠缺失图片才能完成的身份或商品复刻才索要图片。

## 默认视觉方案

未指定时采用：一位明确成年的原创女性模特；1:1 方形画幅；左侧人物占约 70%，右侧广告栏占约 30%；头顶到大腿中段；平视、轻微三分之二侧身站姿；奶油白与浅金配色；虚构品牌 LUNE。角色细节从输入继承，缺失时协调补全，不固定套用银发、龙角等文章角色。

**画风**：纯日系二次元面容，清晰有神的眼睛、简化鼻部、小巧自然的嘴；干净线稿与有组织的发束，赛璐璐大色块结合局部柔和厚涂，肌肤高光克制，蕾丝与珠宝有细节。不要同时要求写实皮肤毛孔、3D 建模和纯二维脸。用户明确选择 3D CG 时整套切换，不附加“禁止半写实”的冲突约束。

**商品**：默认同色系蕾丝文胸与配套三角内裤，写清肩带、罩杯、包边、腰带、花纹与一处装饰。需要覆盖的部位有不透明衬里，花边保持网纱与刺绣的层次。缎面用宽而柔的反光，刺绣用细密凸起纹理，金属只用少量亮点。不要把“内衣”自动替换成长裙或宽松外套；用户指定的合规款式应保留。

**动作**：写出身体朝向、重心、两只手的位置、腿部状态、视线与表情，使动作能被画出来。轻微回眸、坐姿、平躺都按空间关系描述，不机械改成站姿。“自信”可落实为平视、放松肩颈、稳定重心；“柔和”可落实为眼睑放松和轻微微笑。不要所有角色都变成无辜、脸红、嘴唇微张。

**场景与光色**：背景服务人物与服装。可用简洁影棚、浅色室内、沙发、床品或用户场景；决定一个主光方向、冷暖关系与少量道具。肤色从脸到四肢保持一致；主视觉和布料细节图使用同一套衣服与相近光色。避免用“高级、梦幻、8K”代替具体视觉描述。

## 版式选择

选一个与用户请求相符的布局，不把所有模板叠加。需要完整范例时读 [references/templates.md](references/templates.md)。

| 请求 | 画面分区与动作重点 |
| --- | --- |
| 单人广告，未指定布局 | 左 70% 人物，右 30% 广告；明确头顶和下方裁切位置 |
| 双人同框 | 横幅优先，左约 72% 双人、右约 28% 广告；明确左右位置、各自手臂归属、接触点与服装配色；用户指定方图则保留 |
| 正反面、等身展示、三栏 | 左 1/3 正面，中 1/3 背面，右 1/3 广告；同一角色的两次展示，不是两个人物；全身请求要给头脚留边距 |
| 举牌或主题海报 | 人物与广告分栏；写明道具位置、大小、握持点及牌上原文；商品保持穿着，避免道具遮完所有商品结构 |
| 用户指定竖版或无文字 | 保留画幅；竖版可改为上人物下信息；无文字采用独立产品与面料展示区，不再硬加品牌字样 |

比例描述针对画布区域，不是角色占画面的面积。长发、翅膀、尾巴可在主视觉内舒展，不穿入广告正文。三栏不能同时要求“单一连续场景、无分栏”；裁到大腿不能同时要求双脚完整可见。

## 把广告区真正设计出来

不要只写“右侧加高级广告”。写出可落地的信息层级：

- 顶部一个品牌名，按用户拼写；缺失时使用虚构名并简短说明。品牌通常只出现一次，除非用户要求重复。
- 一句短主标语；默认中文文案配少量英文小标题。日系风格不等于必须日语；指定日语时用简短自然句子。
- 两到三个有实际内容的模块：蕾丝花纹、缎面织物、肩带连接或饰件。小图是商品细节，不是身体部位特写；花纹和颜色须与模特穿着一致。
- 每模块一句短说明，避免长段小字。未提供真实产品数据时不编造成分比例、认证、功效、售价或促销。
- 明确奶油白底、细分隔线、留白、对齐、大标题与小正文的字号层级；装饰取自角色或商品的花形、宝石色等共同元素。

提示词内逐字列出需要渲染的文案，并要求只出现这些文字。保留“无额外水印、无乱码”，不要套用“无文字、无 logo”来取消已要求的广告。用户若要求无字版本，则明确取消全部文字。

## 组装与检查

按画幅与用途 → 人物与画风 → 服装 → 姿态和取景 → 场景光线 → 版式与逐字文案 → 少量排除项的顺序组织最终提示词。可写自然段或短模块，不必凑固定字数。

输出前检查：

- 输入中明确的人数、色彩、身份特征和文字是否保留；没有依据的添加是否只是必要的设计补足。
- 商品是否仍是内衣、款式可辨；服装结构和材质是否比泛泛审美词更具体。
- 镜头、裁切、肢体、分栏与文字要求是否相容；多视图身份与服装是否一致。
- 广告栏是否有明确空间、内容和层级，是否会被人物遮挡。
- 画风是否统一，排除项是否误伤用户要求。只保留本画面相关问题，如错手、串色、裁脚、乱码或商品结构变形。

本技能用于成年人物的非露骨内衣商业插画。不能只加一个成年年龄标签来保留明显未成年外观，也不把裸露、色情动作或恋物特写通过广告包装和同义词隐藏。遇到此类输入，简短说明并提供实质调整后的成年商业方案；普通内衣、自然体态与合规姿态不需要反复免责声明。

原文的提示词和图片是视觉参考，不是模型政策文档。不要继承“某词必拦截”“换词必通过”或反复重试以规避限制的操作。来源取舍见 [references/source-notes.md](references/source-notes.md)，仅在需要追溯参考时读取。
