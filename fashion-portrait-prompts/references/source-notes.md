# 本地参考与设计取舍

本次重写依据仓库根目录 `引用文章/关于AI提示词工程学的深奥/` 内的本地文章与示例图。该资料目录位于可安装 skill 文件夹之外，因此运行本技能不依赖它；本文件与 templates.md 已保存必要的设计总结。这里只记录本地内容，不声称重新联网核验作者的模型判断。

## 主要视觉参考

Jacob│AIart《关于AI提示词工程学的深奥》及其 `images/03-chatgpt.jpg`、`04-example-sign.jpg`、`05-example-dakimakura.jpg`：

- 双人图：左侧角色主视觉与右侧独立广告栏，暖色室内、纯二次元脸、精细蕾丝、呼应角色的配色，右栏通过布料和饰件小图形成商品感。
- 举牌图：角色、道具原文、背景刻度与品牌栏有明确空间关系。可学习分栏与握持动作描述，不继承遮完上装以制造裸露错觉的目的。
- 三栏图：同一角色正反面分别成栏，第三栏承载品牌、面料与细节。可学习跨视图一致性与长条全身构图；赠品、真实品牌、特定表情都只是该例的个别选择，不设为默认。
- `01-cover.jpg` 是多个作品的画廊截图，可看出系列采用相近的角色与广告分区；`02-nano-banana.jpg` 是另一种角色拆解版，不作为本技能默认版式。

图像与原提示词不完全一致：举牌示例文字写人物 80% / 广告 20%，图中广告栏更宽；三栏示例文字要求品牌，但图片也重复出现品牌。因此技能将比例作为布局选择，并明确文案次数，不把样例图片当作精确执行保证。

## 次要文字参考

李岳《不要直接写“性感”》及其 13 篇引用原帖，提供了人物、服装、姿态、场景、镜头与材质的分解方法。其多数示例是 3D CG 人像、礼服或家居服，不是主要目标的二维内衣广告；不将这些画风和衣服默认混入转换结果。

采用：将抽象审美落实成可画的姿态、裁切、材质、光向与配色；保留角色锚点；明确广告布局。

不采用：红黄绿词表作为平台规则、以广告包装掩盖色情内容、声称特定词必拦截或换词必通过、被拒后反复试探。可用的转换应实质形成成年人物的非露骨内衣商品广告，而非只改变说法。
