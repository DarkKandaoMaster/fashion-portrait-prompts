# 完整转换示例

用于把握设计密度与输入保真，不是固定角色库。实际输出要替换为用户的锚点、服装、文案及画幅；每次只选择适合的构图。以下均为原创成年角色的非露骨商品广告。

## 1. 短关键词 → 单人广告

输入：`银紫长发，紫眼，白色蕾丝，月亮，清冷，内衣广告`

输出前可说明：未指定品牌，采用虚构品牌 LUNE，默认方形双栏。

```text
创作一张 1:1 方形日系精品内衣广告插画。画面左侧 70% 为角色主视觉，右侧 30% 为独立奶油白广告栏，中间用细浅金线分隔。

主角是一位约 25 岁的原创成年女性，成熟自然的脸型，银紫色长发，紫色眼睛，耳侧一枚小巧月牙发饰。保留纯日系二次元面容，鼻部简化，眼睛清晰有神，唇形小巧；干净线稿、清楚的发束、大色块赛璐璐上色与局部柔和渐变，避免写实脸与塑料皮肤。

她穿珍珠白蕾丝文胸和同系列三角内裤。文胸采用细肩带、清晰的罩杯与下围结构，蕾丝为细小月牙与花叶刺绣，内层有不透明衬里；下装用相同花纹、柔软缎面包边及一枚小银色月牙吊饰。服装结构完整，重点呈现刺绣层次、缎面柔光和精致连接件。

镜头平视，取景从完整头顶到大腿中段。人物身体向画面右侧轻转，面部看向观众，表情安静清冷；肩颈放松，重心落在右腿，左膝轻微放松；右手自然垂于身侧，左手轻扶耳侧发饰，手臂不遮住主要商品结构。长发在左侧舒展，不伸进广告栏。

背景是浅米色简洁室内，远处只有柔焦弧形墙面。左上方柔和暖白光照亮人物，银紫发色与珍珠白面料形成冷暖层次，脸、颈、手臂与腿部肤色统一，亮部不过曝。

右栏顶部用大号精致衬线字显示一次“LUNE”，下方主标语为“月光般的轻柔”。中段纵向排列三张商品小图，依次是独立蕾丝布样、缎面包边、月牙连接饰件，与模特衣服保持同色同纹。每张图下分别显示“月牙刺绣”“柔软缎边”“精致细节”。底部小字为“LACE COLLECTION”。各模块左对齐，线条轻细，留白充足，月牙装饰仅点缀边角。画面只显示上述文字，不添加其他品牌、价格或水印。

保持自然人体比例与正确手指，避免多余肢体、花纹糊成噪点、人物压住广告文字、乱码和半写实脸。
```

## 2. 角色设定 → 双人横幅

输入：`两位成年原创女性，橘发金眼花饰、银发紫眼龙角，橘白配色，坐沙发对视，16:9，品牌 AUREL`

```text
生成 16:9 日系二次元精品内衣品牌横幅，左 72% 是两位成年女性的沙发同框主视觉，右 28% 是独立象牙白广告栏，以浅金细线分隔。

左侧角色 A 为橘色长发、金色眼睛、橙花发饰，穿暖橘色花卉刺绣文胸与同款三角内裤，配细金色连接件。右侧角色 B 为银色长发、紫色眼睛、对称龙角与小型银色耳饰，穿珍珠白蕾丝文胸和配套三角内裤，配银色连接件。两套内衣都有完整罩杯、肩带、下围与不透明内衬。保持各自发色、眼睛、饰品和服装归属，不能互换。

两人自然坐在浅米色沙发上，身体轻轻转向彼此，温柔对视。A 的右手放在自己的膝上，左手轻搭沙发靠背；B 的双手自然相叠放在自己的腿上。肩膀放松，双腿自然并拢斜放，无夸张扭转。镜头平视，构图从完整头顶到膝部，龙角和发饰留足边缘，手臂轮廓彼此清楚。

画风为纯二次元角色 CG，眼睛细腻、鼻部简化，干净线条与柔和赛璐璐上色，蕾丝、缎面和金属分别表现不同反光。左上方暖光统一照亮两人，奶油白、橘金和淡紫相互呼应；背景只保留窗帘与少量虚焦花卉，不抢人物。

广告栏顶部仅一次“AUREL”，主标语“各有光彩，同样柔软”。下方排列橘色刺绣布样、白色蕾丝布样和两色连接件的商品细节小图，对应短标题“花卉刺绣”“细腻蕾丝”“同系列设计”。底部“DUO COLLECTION”。标题突出，正文短而清晰，留白充足；装饰沿用橙花与银色弧线，不添加其他文案。

避免人物融合、手臂归属不明、龙角数量错误、服装串色、广告栏被头发遮挡、文字乱码及额外水印。
```

## 3. 正反面展示 → 三栏广告

输入：`成年原创红发角色，白金内衣，正反面等身，柔软床品，三栏，品牌 SOLÉ，1:1`

```text
制作 1:1 方形日系精品内衣广告，画布从左到右严格分为三个约等宽的纵向栏，以浅金细线隔开。左栏为同一位成年角色的正面全身展示，中栏为她的背面全身展示，右栏是品牌与商品信息。前两栏是两个独立视图，不是在同一张床上出现两个角色。

角色为约 26 岁的原创成年女性，红色长发、琥珀色眼睛、金白花形发饰，成熟匀称的体态。两幅视图脸型、发色、体型与配饰一致，均穿白色刺绣文胸与配套三角内裤，浅金包边和花形小饰件相同。文胸正面罩杯、背面扣带与肩带连接符合一套真实服装的结构，面料有不透明衬里。

左栏采用轻微俯视的完整全身构图：人物自然仰躺在奶油白床品上，头枕柔软枕头，一只手放于枕旁，另一只手放于身侧；双腿自然伸展，一侧膝盖略微弯曲，神情放松、轻微微笑。中栏采用相近俯视角：人物自然俯卧，双臂放于枕旁，头轻转使侧脸可见，长发拨至一侧露出背部扣带，双腿舒展，腰背自然，不刻意拱腰。每栏都完整容纳头顶至双脚，四周留边距，不突出身体局部，不增加脚部特写。

画风保持纯日系二次元，清晰线稿、柔和赛璐璐与局部厚涂，肌肤色调统一。两栏光线都来自左上方，床品呈宽而柔和的缎面反光，刺绣有细密清晰的层次，整体为奶油白、浅金与红发的温暖配色。

右栏为象牙白底，顶部品牌“SOLÉ”只出现一次，主标语“每一面，都从容”。下方三个纵向模块分别展示花形刺绣布样、缎面包边、背扣与肩带结构，文字依次为“花形刺绣”“细腻包边”“完整剪裁”，底部小字“LINGERIE COLLECTION”。小图和主图商品保持一致，广告区留白充分，细金边框只点缀边角。只渲染这些文字，不额外添加赠品、价格、促销或标志。

避免同一人物前后造型不一致、裁掉头脚、脊椎扭曲、背面服装结构错误、跨栏融合、广告小字拥挤及额外水印。
```

## 变体处理

- 举牌：按用户文字设计牌面，明确两手握左右边缘、牌面朝向镜头。牌的位置服务版式与叙事，不要求制造未穿衣的错觉；可置于腰侧或让部分商品结构清楚可见。
- 无字海报：取消示例里的所有品牌与标语，把信息栏改成统一底色的产品平铺图与面料样片；不要同时保留“仅出现以下文字”。
- 有参考图：把示例的原创外观段替换为实际识别出的角色锚点。广告参考与角色参考分别说明用途，不能把广告中的角色误当成用户要的人物。
- 用户只要最终提示词：省略输入解释、默认说明和模板标题，直接给可用正文。
