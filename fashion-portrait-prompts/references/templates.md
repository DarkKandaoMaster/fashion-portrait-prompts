# 提示词模板与示例

以下均为重新编写的示例，不是原帖逐字复刻，也不代表特定模型的成功率。只保留当前任务所需模块。

## 改写示例：保留氛围，改变实际内容

下列输入摘要只用于说明取舍，不需要在实际回答中复述用户的露骨段落。

### 示例 A：透视服装与暴露要求

输入摘要：成年角色，黑色蕾丝、暖色卧室、侧坐；原文要求透视并暴露私密部位。

```text
创作一张 4:5 竖版成年女性时尚插画。保留原设定的发型、发色与标志性配饰，采用干净线稿和柔和赛璐璐上色。

角色穿黑色蕾丝装饰的及膝居家连衣裙，胸前、腰腹和裙身均有完整不透明内衬，衣领与裙摆稳定覆盖身体，蕾丝纹样清晰可见。她侧坐在床沿，双膝自然靠拢，双手放在膝上，肩膀放松，神情平静自信。

平视取景，从头顶到小腿，人物及裙摆完整入画。保留暖色卧室和柔和床品，侧面灯光表现衣料纹理与面容，画面重点为角色气质与服装设计。所有私密部位由衣物完整覆盖，面料不透视，不出现性行为或私密部位特写。
```

取舍：保留黑色蕾丝、侧坐和卧室氛围；将透视与暴露改为实质性的衣物覆盖。

### 示例 B：举牌构图

输入摘要：成年角色正面举牌，冷色背景；原文想依赖牌子制造裸体效果。

```text
创作一张 1:1 正方形成熟女性角色插画，沿用用户指定的画风、发色及配饰。角色穿奶油白不透明无肩带上装与深蓝色高腰半身裙，上装稳定固定并完整覆盖胸部，裙身覆盖腰胯及大腿。

人物正面站立，双手自然握住一块黑色横牌的左右两侧，牌子置于胸前，保留可见的衣物边缘与肩颈线条。牌子正面仅显示用户指定的短文案。平视取景，从头顶到膝下；背景为简洁冷灰墙面，柔和侧光形成清楚的明暗层次。重点呈现人物表情、举牌动作和配色，不添加广告栏。人物保持完整穿着。
```

取舍：保留举牌动作和冷色构图，增加实际衣物；用户没有文案时省略牌面文字。

### 示例 C：性化互动改为普通双人互动

输入摘要：两个成年虚构角色，月夜、蓝紫色光影与明确性行为要求。

```text
创作一张蓝紫色月夜主题的双人幻想插画，两位人物均为成年人。保留各自的发型、配饰和原有主色，采用用户指定的插画风格。

两人穿着完整的不透明幻想风服装，并肩坐在露台长椅上，一人轻握另一人的手，彼此自然对望，表情温柔平静，双腿与双手位置清楚。以平视双人中景呈现，画面包含完整头部与坐姿，视觉中心位于面容和握手动作。

月光勾勒发丝与衣料边缘，背景保留星空和少量柔和光点，重点表现陪伴感、服装纹理与色彩层次，所有私密部位完整覆盖，不出现性行为。
```

取舍：保留人物关系、月夜与蓝紫光影，舍弃性行为及相关细节。

## 示例一：保留参考角色的二维服装广告

```text
根据上传的成年角色参考图，创作一张 1:1 正方形日系服装广告插画。保留参考角色的发型、发色、瞳色与标志性发饰，服装改成奶油白针织开衫与深蓝色长裙。

采用清晰线稿和赛璐璐色块，配少量柔和渐变；五官保持二维简化表现。角色正面站立，轻微侧身，肩膀放松，双手在腰前轻握手袋，目光看向镜头，嘴角自然微笑。取景从头顶到小腿，帽饰与手袋完整入画。

画面左侧约 75% 为人物区，右侧约 25% 为文字区，以细竖线分隔。人物、发丝及手袋均不越过分隔线。右侧上方仅出现一次品牌名“示例品牌”，下方两行分别为“秋日针织”和“奶油白 × 深蓝”，保留充足空白，不添加其他文案。

背景为浅米灰色，柔光从画面左上方照入；突出针织纹理、裙摆褶皱和人物面容。不要摄影式写实脸，不要额外人物或道具。
```

## 示例二：成年泳装产品 Lookbook

仅适用于用户确实需要泳装展示的任务；不把 Lookbook 当作其他内容的包装。

```text
创作一张 4:5 竖版泳装产品 Lookbook，呈现一位明确成年的女性模特。她穿深蓝色运动款连体泳衣，侧缝为浅蓝色拼接，面料为细腻哑光织物。

人物站在泳池边的浅色地面上，重心落在一条腿上，另一条腿自然放松；双臂垂于身侧，目光看向镜头，神情自信平静。平视拍摄，头到脚完整入画，上下保留适量空白。

重点展示泳衣正面的拼接、肩带结构与整体版型，保持自然人体比例。背景只保留浅蓝池水和干净地面；柔和日光从左侧照入，避免反光掩盖面料细节。画面不添加文字和标志。
```

## 示例三：三栏角色服装设定展示

借鉴原文的分区思路，用于明确的正背面展示需求。用户只要单张人像时不加多栏。

```text
创作一张 3:2 横版日系角色服装设定图，三栏自左向右宽度约为 35%、35%、30%，各栏之间保留窄留白。

左栏：参考图中的成年角色正面全身站姿，双手自然垂放，头到脚完整入画。
中栏：同一角色的背面全身站姿，保持相同身高、发型、服装配色与比例。长发自然束起，使外套背部图案可见。
右栏：展示衣领、袖口和面料纹理三个细节小图，不出现第三个人物。

角色穿深蓝色短外套、奶油白衬衫、灰蓝色长裤和黑色短靴。主画风为干净线稿与柔和赛璐璐上色。前后视图采用相同的中性柔光、比例和地面基线；纯浅灰背景，不加文字。
```

## 示例四：只修正被裁切的全身图

```text
保留现有图像的角色面容、发型、服装、配色和主光方向，只调整取景与人物尺度。镜头拉远，使角色从头顶到鞋底完整入画，上下留出空白；保持原有姿态和自然人体比例，不通过拉长身体填满画幅。背景沿原场景自然延展，不添加人物或道具。
```

这类修正需要实际输入现有图像；没有输入图时，应把保留项写成已知特征，而不声称已完成图像编辑。
